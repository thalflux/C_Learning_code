# Mes exercices en langage C

Ce dépôt regroupe mes programmes et exercices d'apprentissage du langage C réalisés sous VS Code avec GCC.

## Contenu du dépôt
- Calculs mathématiques (volume d'une sphère, factorielle)
- Structures conditionnelles (`if / else if / else`, `switch`)
- Boucles (`for`, `do ... while`)
- Manipulation de tableaux

## Compilation et exécution
Pour compiler un fichier source avec GCC :
```bash
gcc nom_du_fichier.c -o programme.exe
./programme.exe
